# Artes dos banners

Complemento manual de 25/10/2026: os dez banners dos cinco jogos têm imagem. As oito imagens faltantes foram conferidas por publicação/personagem e responderam HTTP 200 com conteúdo de imagem. Datas, preferências e leitura das notificações são preservadas. Sem integração automática.

Skirk e Escoffier mantêm as imagens oficiais já cadastradas. HSR e ZZZ usam artes oficiais da HoYoLAB; WuWa usa as artes dos banners publicadas no WuWa Wiki, e Akane Rin usa a arte do Limited Board identificada pelo SenseOS como proveniente da publicação da editora no Steam. Os arquivos pertencem às respectivas editoras.

O cadastro inicial já inclui as imagens. Para uma base com a carga anterior, [este complemento SQL](../db/seeds/game-agenda-images-2026-10-25.sql) preenche somente imagens ausentes nas mesmas edições. Não sobrescreve uma imagem escolhida manualmente. Links externos podem mudar; a interface oculta imagens que não carregam e mantém os textos.
